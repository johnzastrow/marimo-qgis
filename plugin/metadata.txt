about=Adds a toolbar button that opens the "marimo" manager panel, where you can
    launch any marimo notebook (.py file) in your browser as a detached
    subprocess. Notebooks get a live HTTP bridge to the running QGIS project
    (read layers, selection and canvas extent; push results back as new layers)
    via the bundled qgis_bridge client; they also have full PyQGIS access.

    Requires uv (https://docs.astral.sh/uv/) on PATH and a project virtualenv
    created with --system-site-packages so the notebook kernel can import PyQt6.
